My Portfolio website 



## 🚀 Features

* **Project Showcase:** Detailed case studies for individual projects (e.g., SilentVoice AI, HelixDesk AI, Barcode Generator, Vitality AI).
* **Journal:** A section dedicated to my thoughts on building, creating, and technology.
* **Responsive Design:** Fully responsive layout optimized for desktop, tablet, and mobile viewing.
* **Modern UI/UX:** Built with a clean, dark-themed aesthetic featuring smooth scroll animations, custom cursors, and parallax effects.
* **Functional Contact Form:** Integrated with Web3Forms for seamless, serverless email delivery straight to my inbox, complete with honeypot spam protection.

## 🛠️ Built With

* **HTML5:** Semantic structure for accessibility and SEO.
* **CSS3:** Custom styling, CSS variables for design tokens, Flexbox/Grid layouts, and responsive media queries.
* **JavaScript (Vanilla):** Dynamic interactions including custom cursors, scroll reveals, page transitions, and form handling.
* **Web3Forms API:** Serverless contact form submissions.

## 📂 Project Structure

* `index.html`: The main landing page.
* `about.html`: Detailed background, skills, and certifications.
* `projects.html`: Full grid of all selected works.
* `project-detail-*.html`: Individual project case studies.
* `journal.html` / `journal-detail.html`: Blog and thought entries.
* `contact.html`: The contact form page.
* `css/`: Modular stylesheets for global design, components, and animations.
* `js/`: JavaScript files for interactivity and dynamic data loading (`site-data.js`).
* `assets/`: Images and visual assets for the site.
